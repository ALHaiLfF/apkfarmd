# Рыбачка ひめ — Android

Телефонная версия авто-рыбалки для Slayers 2: то же самолечащееся «ядро» и аниме-панель, что на ПК,
но всё работает на самом телефоне (Python внутри приложения через Chaquopy).

## Как собрать APK (в облаке, без Android Studio)
1. Создай репозиторий на github.com (New repository, любой, можно приватный).
2. Загрузи в него ВСЁ содержимое этой папки (Add file → Upload files), включая скрытую папку `.github`.
3. Вкладка **Actions** → «build-apk» запустится сама (или «Run workflow»). Через ~10 минут готово.
4. APK: вкладка **Releases** справа (или Actions → запуск → Artifacts → SakuraFishing-apk).

## Первый запуск на телефоне
1. Установи APK (разреши установку из этого источника).
2. Открой «Рыбачка» → в панели блок «Настройка телефона»:
   - **Управление касаниями** — включить службу «Рыбачка» в спец. возможностях.
   - **Видеть экран** — разрешить запись экрана (выбирай «весь экран»).
   - **Точка заброса**, **Кнопка «Собрать»**, **Слот удочки** — «Указать», зайти в игру, дойти до нужного места,
     нажать на плашке «Выбрать» и тапнуть по нужной точке.
3. «Начать рыбалку». Дальше всё само: если Roblox свернули — вернёт, если рассинхрон — починит.
   На экране поверх игры есть сакура-кнопка (старт/стоп), её можно перетащить.

## Структура
- `app/src/main/java/...` — Kotlin: захват экрана, касания/удержание, кнопка поверх игры, оболочка WebView.
- `app/src/main/python/` — мозг (`brain.py`), детектор, панель; `android_world.py` связывает их с телефоном.
- `tools/phone_test.py` — проверка питон-части с поддельным мостом (без телефона).
